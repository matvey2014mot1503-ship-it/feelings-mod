# Feelings Blocks

Мод для Minecraft (Fabric 1.20.1): шесть декоративных блоков с разными текстурами.

Блоки: любовь, жадность, вера, моггинг, жестокость, гейство.

## Сборка
Нужны JDK 17 и Gradle 8.5+.

    gradle build

Готовый jar появится в `build/libs/`. Положите его в папку `mods` вместе с Fabric API.

Также jar собирается автоматически в GitHub Actions (вкладка Actions → Artifacts).
